# MANARA theme

* `src/resources/themes/Manara.json` — chat bubble theme (orange/blue from the
  logo), selectable in Settings → Theme. Built from ClassicSlate with the MANARA
  palette; follows the same schema (themes/SCHEMA.md). It is the default
  (`IDS_THEME_VAL`). `ClassicSlate` remains the compiled-in fallback: if a theme
  fails to load, `core/theme.cpp` falls back to it, so a mistake in Manara.json
  cannot leave the chat without a theme. Tests name ClassicSlate explicitly and
  do not depend on the default.
* `src/resources/qss/manara-light.qss` / `manara-dark.qss` — application style
  sheets using the real object names (MainWindow, frame, lblUserName, lblStatus,
  txtNote, wgtToolBar, tvUserList, ChatWindow, txtMessage, toolBar, splitter,
  TransferWindow, lvTransferList, btnClear, btnClose, SettingsDialog,
  lvCategories). To try one, copy it to the user theme folder as `custom.qss`
  (read at startup by `applyCustomQss`).
* Tokens: `docs/design/tokens.json`. Icons: `docs/design/icons/`
  (the ICO also replaces `src/app/lmc.ico` and `src/resources/icons/lmc.ico`).

Status: JSON is valid and keeps the schema's shapes; QSS syntax and the look
have **not** been checked in a running Qt GUI (this build had no QtGui).

## Update: built-in style (v0.3)

- The MANARA light/dark style sheets are now compiled in (`:/qss/`) and applied automatically at startup according to the system colour scheme. A `themes/custom.qss` file still overrides them.
- The contact list is painted as cards (round avatar, status dot, note line). Icons (`src/resources/images`, 1x and @2x) and the default avatars are generated by `tools/gen_icons.py` and `tools/gen_avatars.py`.
- Verification status: rendered and inspected only in an offscreen Linux build (Qt 6.8.3): main window light, dark (forced), Arabic RTL, chat, and the transfer window with live speed/ETA (the speed seen there was throttled by the test, so it proves the display, not network speed). Not yet inspected on real Windows: fonts, DPI scaling and native dark mode.

## Single window (default)
The people list and the one-to-one chat share one window (list on one side, chat pane beside it).
Chat rooms, the public chat and broadcasts still open as separate windows.
To return to the old separate chat windows set `Window/SingleWindow=false` in the settings file.
Appearance offers Light and Dark only; the first run follows the system colour.
Languages: Arabic (default) and English.
